# Imagens

Coloque aqui as imagens do portfólio e referencie em `content.js`
pelo caminho relativo, ex: `image: "images/projeto-01.png"`.

Tamanhos que o design espera:

| Onde                        | Proporção | Sugerido    |
|-----------------------------|-----------|-------------|
| Cards do hero (`deck`)      | ~16:10    | 1200 × 760  |
| Projetos em destaque        | 16:10     | 1400 × 880  |
| Grade de projetos (`grid`)  | 16:10     | 1200 × 760  |
| Retrato (`photo`)           | 4:5       | 1000 × 1250 |

As imagens são cortadas com `background-size: cover`, então o assunto
principal deve estar no centro. Prefira `.webp` ou `.png` otimizado —
tudo aqui é servido estaticamente pelo GitHub Pages.
