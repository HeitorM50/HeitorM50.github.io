## Contexto

O CoOps foi construído para medir como equipes de desenvolvimento colaboram no GitHub. O produto reúne dados dos repositórios, apresenta dashboards em D3.js e usa uma camada de IA para resumir os resultados em texto.

## O problema

O processamento original tornava a análise pouco prática: o pipeline levava aproximadamente quatro horas. Além disso, os dados precisavam ser apresentados de uma forma que não exigisse leitura manual de todas as métricas.

## Minha contribuição

Trabalhei na interface React, no pipeline de dados em camadas, na suíte de testes com pytest e na automação de entrega. O projeto contou com seis pipelines de CI/CD e foi conduzido em equipe sob Scrum.

Minha participação soma 47 commits.

## Resultado

A reorganização do pipeline reduziu o processamento de cerca de **quatro horas para aproximadamente 30 segundos**. Os dashboards e a síntese em texto transformaram os dados coletados em uma leitura mais direta sobre colaboração.
