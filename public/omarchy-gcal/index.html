Google Calendar for Omarchy

A Google Calendar widget for the Omarchy bar.

A calendar icon that sits in the Omarchy status bar. Click it for your next few days of events; get a native desktop notification before each one starts, using the reminders you already set in Google Calendar. Clicking a notification joins the meeting.

Install

omarchy plugin add https://github.com/HeitorM50/omarchy-gcal --enable

Then connect your Google account:

~/.config/omarchy/plugins/io.github.heitorm50.gcal/bin/gcal-auth

You create your own Google OAuth client during setup — this plugin ships no client ID and no relay server, so your calendar traffic never passes through anyone else's project.

How it works

  • Read-only access to your primary calendar (calendar.readonly).
  • You create your own OAuth client — no shared app, no third-party proxy.
  • No OAuth token ever enters the desktop shell process, and none is ever passed on a command line.
  • Reminders are scheduled as transient systemd user timers, not a polling loop.
  • Each event carries its Google Calendar colour as a small dot.
  • Works offline: the last synced agenda stays on screen.
